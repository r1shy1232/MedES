    How it works

    Confidence scores

    The score shows how closely your answers match the symptom pattern this app uses for a condition. It is not a medical probability, not a diagnosis and not a guarantee.

    Logic

    Each condition has rules: AND (required symptoms must all be present), OR (a minimum number of optional symptoms) and NOT (symptoms that rule it out). Age and history can slightly raise the score. Emergency warning signs are checked first and always shown above results.

    NHS-only information

    All medical wording comes from NHS pages, each linked on the result. If the app has no NHS information for a question it says so rather than guessing. Pages can change, so always check the linked NHS page.

    Privacy

    No account is needed. Nothing you type is saved, stored or sent anywhere: it is processed in your browser only.

    Limitations

    Only a small number of conditions are included so far. A missing result does not mean nothing is wrong. Speak to a doctor if you are worried.
